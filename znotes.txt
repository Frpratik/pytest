============================Pytest==============================
1.pip install pytest >>> installation 

2.Running pytest without mentioning a filename will run all files of format test_*.py or
  *_test.py in the current directory and subdirectories.
  
3.Pytest requires the test function names to start with test.Function names which are not
  of format test* are not considered as test functions by pytest.
  
4.To run all tests in a directory: pytest

5.To run sinle test file: pytest testfilename.py

6.Pytest provides two ways to run the subset of the test suite:
	a)based on substring matching of test names: pytest -k <substring> -- for all file || pytest -k <substring> <testfile>.py --for specific file
	b)based on the markers applied: Pytest provides many inbuilt markers such as xfail,
	skip and parametrize. Apart from that, users can create their own marker names.
	Markers are applied on the tests using the syntax given below : @pytest.mark.<markername>
	* To run marked tests : pytest -m <markername> --for all files || pytest -m <markername> <testfile>.py --for specific file

7.Fixtures - Fixtures are functions, which will run before each test function to which it is applied.
    Fixtures are used to feed some data to the tests such as database connections, URLs to test and some
	sort of input data : @pytest.fixture
	* A fixture function defined inside a test file has a scope within the test file only.
       We cannot use that fixture in another test file. To make a fixture available to multiple test files,
	   we have to define the fixture function in a file called conftest.py

8.Parameterizing of a test is done to run the test against multiple sets of inputs : @pytest.mark.parametrize
  ex >> @pytest.mark.parametrize("num, output",[(1,11),(2,22),(3,35),(4,44)])
		def test_multiplication_11(num, output):
			assert 11*num == output
		op: three cases will pass and one will not[(3,35)]\

9.Skip and Xfail tests:
	a)xfail: Pytest will execute the xfailed test, but it will not be considered as part failed or passed tests.
	Details of these tests will not be printed even if the test fails :@pytest.mark.xfail
	b)Skipping a test means that the test will not be executed : @pytest.mark.skip

10.Maxfail: to stop the execution of test suite soon after n number of test fails : pytest --maxfail <num> --for all files ||
	pytest <testfile>.py --maxfail <num> --for specific file

11.pytest runs test files sequentially so, if we have large bunch of files and want to run those all files in parallel
	then we can install the pytest-xdist plugin: pip install pytest-xdist
	* now we can rum our test files using multiple workers: pytest -n <num>

12.To generate output in XML file: pytest --junitxml="<resultfilename >> eg.result.xml>" --for all files || 
	pytest <testfile>.py --junitxml="<resultfilename >> eg.result.xml>" --for specific file
